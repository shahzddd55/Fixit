## FixIt Web - Business Website

Simple, responsive multi-page business website: Home, About, Services, Contact.

### Run locally
- Open `index.html` directly in your browser (double click), or
- Serve the folder with a local server:
  - PowerShell: `pwsh -c "cd 'C:/Users/shaja/OneDrive/Documents/FIXIT WEB 2'; python -m http.server 8080"` then open `http://localhost:8080/index.html`

### Customize
- Edit text in the `.html` files.
- Update theme in `assets/css/styles.css`.
- Add behavior in `assets/js/main.js`.

### Deploy
- Upload the whole folder to any static hosting (GitHub Pages, Netlify, Vercel, S3).
